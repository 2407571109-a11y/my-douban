我的豆瓣

条目 · 五星 · 短评长评 · 想看/在看/看过/弃了 · 标签 · 时间线 · 年度统计。
把那套机制搬回你自己的机器，零依赖，断网能开。

这是源码仓库，不是在线应用 页面需要本地后端提供接口，所以请 clone 下来跑 python app.py。 直接打开 GitHub Pages 只会看到这个说明页。

运行

git clone https://github.com/2407571109-a11y/my-douban.git
cd my-douban
python app.py            # → http://127.0.0.1:8601

Windows 双击 start.bat 也行。首次启动自动建库，并用 data/seed.json 播种 10 条演示条目。

技术栈

Python 3.8+标准库SQLite原生 JS零外链

  • 后端单文件 app.py：http.server + sqlite3，不装任何第三方包
  • 前端单文件 static/index.html：CSS/JS/图标/图表全内联，无框架无 CDN
  • 封面按片名哈希程序化生成，不依赖图床

接口

GET    /api/health
GET    /api/schema
GET    /api/entries?pageSize=200&startCursor=0
POST   /api/entries          {"properties": {"标题": {"text": "..."}}}
PATCH  /api/entries/<id>     {"properties": {...}}   # 增量
DELETE /api/entries/<id>

不做的事

没有小组、同城、关注粉丝——一个人用不上。没有账号体系——靠 SQLite 文件备份迁移就够了。
